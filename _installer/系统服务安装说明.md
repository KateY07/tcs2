# TCS 被控端系统服务安装包

## 安装

将 OneSetup 安装程序复制到被控端，双击运行，接受 Windows 管理员授权。主控端无需安装此服务。

安装程序会检测已安装的真实 Python（排除 Windows Store 占位程序），将被控端安装到 `C:\ProgramData\TCS`，注册 `tcsd` Windows 服务，设置自动启动、失败重启及 TCP 10122 入站防火墙规则。监听 IPv4/IPv6 双栈；不依赖 sshd。

安装包仅携带主控端公钥，不包含主控端私钥。首次迁移优先保留当前用户 `%LOCALAPPDATA%\TCS\tcs_host_key`，从而保留已信任的主机身份；原目标目录的密钥若存在会先备份。后续成功安装的升级保留服务自己的主机密钥。

请从原手动安装所用的 Windows 用户账户启动安装包，以便找到该账户的 Python 和主机密钥。若改用另一个账户，必须手动指定旧安装目录，不能假定主机身份不变。

安装成功前必须通过：服务进程拥有双栈监听端口、已认证 IPv4/IPv6 请求、Python 实际执行、32 KiB 加密上传内容逐字节一致。自检临时身份随后撤销，服务再次启动。缺少 Python 或任何自检失败都会返回失败，不会宣称安装完成。

## 权限与日志

服务以 **LocalSystem** 运行，受信任主控端的远程指令因此具有系统权限。只部署到你管理的机器，妥善保护主控端私钥。安装目录限制为 SYSTEM 和管理员访问。防火墙规则允许所有网络配置文件上的入站连接；它不等于绕过密钥认证。

- 安装记录：`C:\ProgramData\TCS\install.log`
- 服务记录：`C:\ProgramData\TCS\data\service.log`
- 请求审计：`C:\ProgramData\TCS\data\tcs-audit.log`
- 主机公钥：`C:\ProgramData\TCS\tcs_host_key.pub`

管理员 PowerShell 可检查：

```powershell
Get-Service tcsd
Get-NetTCPConnection -LocalPort 10122 -State Listen
Get-NetFirewallRule -Name TCS-tcsd-TCP-10122
```

若安装失败，请保留日志。失败后可能保留文件、已注册服务或防火墙规则，以便诊断；不要关闭整个防火墙来解决问题。

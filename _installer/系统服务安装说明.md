# 系统服务部署（实验功能）

普通用户请使用 README 的免提权手动安装流程。此脚本保留服务安装、自动启动、恢复策略和防火墙配置，但需要管理员权限；当前未完成真实 SCM 环境验收。

## 固定身份

服务运行于 LocalSystem，使用它自身的用户目录，而不是安装管理员的用户目录：

- 私钥：%SystemRoot%\System32\config\systemprofile\.ssh\tcs_host_key
- 授权列表：%SystemRoot%\System32\config\systemprofile\.ssh\authorized_keys
- 数据与日志：%SystemRoot%\System32\config\systemprofile\AppData\Local\TCS\data
- 程序：%ProgramData%\TCS\tcsd.exe

不提供密钥、授权或数据目录参数。管理员必须预先准备服务账户自己的无口令私钥及授权列表，保护私钥权限；私钥同名 .pub 不要求存在。不要把普通用户的身份无意替换成服务身份。

安装脚本不生成、复制、迁移或临时授权任何密钥。缺少所需文件时在修改服务之前停止。历史安装目录中的密钥不能通过参数继续使用。

## 安装与验证

将当前 tcsd.exe 与 install-service.ps1 放在一起，在管理员 PowerShell 执行脚本。允许参数仅为 ServiceName、Port、PythonPath；默认服务名 tcsd，端口 10122。PythonPath 应是 LocalSystem 可执行的真实解释器，不能使用当前用户的商店别名。

脚本配置 LocalSystem 自动启动服务、失败恢复和入站防火墙，检查该服务进程的双栈监听。成功仅表示服务已监听，不代表端到端认证、Python 或上传验收；这些必须从主控分别测试。

test-service.ps1 仅执行脚本语法和固定路径静态检查，不安装服务、不改变防火墙。旧脚本保存在 legacy 文本存档中，不能用于现行部署。
